# تطبيق مكتب الأستاذ العوضي عبد الخالق الشريف

تطبيق ويب (PWA) لإدارة المكتب وخدمة الموكلين. يُفتح من رابط ويُثبَّت على الشاشة الرئيسية.

- `docs/PRD.md` — وثيقة المتطلبات
- `web/` — التطبيق (HTML/CSS/JS بدون أدوات بناء)
- `assets/branding/` — الهوية البصرية

## تشغيل محلي

```
python3 -m http.server 8000 -d web
```

ثم افتح http://localhost:8000

> النسخة الحالية تجريبية وكل البيانات وهمية.
