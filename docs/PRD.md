# وثيقة متطلبات المنتج (PRD)
## تطبيق مكتب الأستاذ العوضي عبد الخالق الشريف للمحاماة والاستشارات القانونية

> الحالة: مسودة أولى للمراجعة

---

## 1. نظرة عامة

تطبيق موبايل (أندرويد وiOS) واجهته عربية بالكامل (RTL)، له غرضان:

1. **إدارة المكتب داخليًا:** القضايا، الجلسات، التوكيلات، المستندات، المهام، المحاسبة.
2. **خدمة الموكلين:** متابعة قضاياهم، التواصل مع المكتب، رفع المستندات، الدفع، حجز الاستشارات.

### الأهداف
- تقليل فوات الجلسات والمواعيد القانونية إلى الصفر تقريبًا.
- مركزية كل ملفات القضايا ومستنداتها في مكان آمن.
- تحسين تجربة الموكل وتقليل المكالمات المتكررة بخصوص "القضية وصلت لفين".
- تنظيم الأتعاب والمصروفات وحسابات الأمانة.

### خارج النطاق (حاليًا)
- الربط المباشر مع أنظمة المحاكم الحكومية.
- أي استخدام للذكاء الاصطناعي في القرار القانوني دون مراجعة المحامي.

## 2. المستخدمون والأدوار

| الدور | الصلاحيات الأساسية |
|---|---|
| شريك / مدير المكتب | كل شيء، بما فيه التقارير المالية وإدارة المستخدمين |
| محامي | قضاياه وقضايا فريقه، الجلسات، المستندات، المهام |
| مساعد / متدرب | مهام وقضايا محددة بصلاحية قراءة وتعديل محدود |
| سكرتارية | المواعيد، الاستقبال، رفع المستندات، التواصل مع الموكلين |
| محاسب | الأتعاب، المصروفات، الفواتير، التقارير المالية |
| موكل | قضاياه فقط: متابعة، مستندات، دفع، رسائل |

## 3. الوحدات الداخلية (للمكتب)

### 3.1 إدارة القضايا
- ملف لكل قضية: رقم القضية والسنة، المحكمة والدائرة، نوع القضية، صفة الموكل، الخصوم ومحاموهم.
- أنواع: مدني، جنائي، أسرة، عمل، إداري، اقتصادي، نقض.
- سجل مراحل القضية (تداول، حجز للحكم، طعن، تنفيذ).
- ربط القضايا ببعضها (أصلية، فرعية، مستأنفة).

### 3.2 الجلسات والمواعيد
- رول الجلسات اليومي والأسبوعي والشهري.
- تسجيل قرار الجلسة والتأجيل والجلسة القادمة من الموبايل بسرعة.
- تنبيهات قبل الجلسة، وتنبيهات مواعيد الطعن والسقوط مع حساب تلقائي للميعاد (بمراجعة المحامي).
- توزيع الجلسات على المحامين وكشف التعارض.

### 3.3 التوكيلات
- أرشيف التوكيلات (عام، خاص، قضايا): الرقم، التاريخ، مكتب التوثيق، الأطراف.
- تنبيه قبل انتهاء أو إلغاء التوكيل.
- ربط كل توكيل بالقضايا التي استُخدم فيها.

### 3.4 المستندات
- مسح بكاميرا الموبايل مع OCR عربي.
- تصنيف حسب القضية ونوع المستند.
- صلاحيات دقيقة للاطلاع، ونسخ احتياطي مشفر.
- مكتبة نماذج: صحف دعاوى، مذكرات، إنذارات، عقود.

### 3.5 المهام والفريق
- مهام بمسؤول وموعد وأولوية (تقديم مذكرة، استخراج صورة رسمية، إعلان بمحضر).
- متابعة المندوبين ومصروفات الانتقال.
- عرض حمل العمل لكل محامي.

### 3.6 المحاسبة والمالية
- اتفاقات الأتعاب: مقطوعة، بالجلسة، نسبة، اشتراك شهري.
- جدول دفعات وتذكير بالمتأخرات.
- مصروفات القضية (رسوم، خبراء، انتقالات) مع صور الإيصالات.
- فواتير وإيصالات وكشف حساب.
- فصل **حسابات أمانة الموكلين** عن إيرادات المكتب.
- تقارير: أرباح كل قضية، أرباح كل محامي، المتأخرات.

### 3.7 العملاء المحتملون (CRM)
- تسجيل الاستشارات الأولية وتحويلها لموكل.
- **فحص تعارض المصالح** تلقائيًا قبل قبول القضية.
- تتبع مصدر العميل.

### 3.8 الأبحاث القانونية والمساعد الذكي
- مكتبة تشريعات وأحكام مع بحث.
- مذكرات سابقة كنماذج قابلة لإعادة الاستخدام.
- مساعد ذكاء اصطناعي لتلخيص المستندات واقتراح مسودات، **مع مراجعة بشرية إلزامية** ودون مشاركة بيانات الموكلين مع أي جهة خارجية دون ضوابط.

## 4. وحدات الموكلين

- حساب موكل بتحقق برقم الموبايل (OTP).
- متابعة القضية: آخر مستجدات بلغة مبسطة، الجلسة القادمة، الحالة العامة.
- رفع المستندات المطلوبة وتتبع ما ينقص.
- محادثة مباشرة مع المحامي أو السكرتارية، مع تكامل واتساب.
- حجز استشارة (بالمكتب، مكالمة، فيديو) مع دفع الاستشارة.
- دفع إلكتروني: فوري، إنستاباي، فودافون كاش، كروت.
- فواتير وكشف حساب لكل قضية.
- توقيع إلكتروني على عقود الأتعاب والإقرارات.
- إشعارات قبل الجلسة بيوم، وعند أي قرار أو تأجيل.
- قسم تعريفي: مجالات المكتب، الفريق، أسئلة شائعة، بيانات التواصل.

> المحامي هو من يقرر ما يظهر للموكل من تفاصيل كل قضية.

---

## 5. الأمان والخصوصية

- أدوار وصلاحيات دقيقة، وتوثيق ثنائي للموظفين.
- تشفير البيانات أثناء النقل والتخزين.
- سجل تدقيق لكل دخول وتعديل.
- إخفاء القضايا الحساسة عن غير المصرح لهم.
- الالتزام بسرية المهنة وبقانون حماية البيانات الشخصية رقم 151 لسنة 2020 وضوابط نقابة المحامين (تُراجع مع مستشار قانوني قبل الإطلاق).
- لا مفاتيح ولا بيانات حقيقية داخل المستودع؛ كل الأسرار في GitHub Secrets، والتجارب ببيانات وهمية.

## 6. اعتبارات خاصة بمصر

- واجهة عربية RTL بالكامل، مع إنجليزي كخيار ثانٍ.
- **وضع أوفلاين** مع مزامنة لاحقة (ضعف الشبكة داخل المحاكم).
- تكامل واتساب كقناة تواصل أساسية.
- تكامل اختياري مع منظومة الفاتورة الإلكترونية (مصلحة الضرائب).
- بوابات دفع محلية.

---

## 7. الهوية البصرية

- **الاسم:** مكتب الأستاذ العوضي عبد الخالق الشريف للمحاماة والاستشارات القانونية
- **اللوجو:** `assets/branding/logo-full.jpg` (ميزان العدالة الذهبي وكتاب مفتوح مع الاسم بخط عربي).
- **الألوان:** كحلي غامق (أساسي)، ذهبي (تفاصيل وأيقونات)، كريمي فاتح (خلفية). تُستخرج القيم الدقيقة من اللوجو عند بدء التنفيذ.
- **الأيقونة:** الميزان الذهبي على خلفية كحلية.
- **شاشة البداية:** اللوجو الكامل على الخلفية الكريمية.
- **الطابع:** رسمي، هادئ، فخم، بمساحات بيضاء واسعة.

---

## 8. التقنية المقترحة

- **الواجهة:** Flutter (كود واحد لأندرويد وiOS، دعم ممتاز لـRTL).
- **الباك إند:** Supabase أو Firebase (تسجيل دخول، قاعدة بيانات، تخزين، إشعارات). القرار النهائي مفتوح للنقاش.
- **البناء والتوزيع:** GitHub Actions لبناء ملف APK تلقائيًا مع كل تعديل.
- **سير العمل:** كل ميزة في Branch منفصل وPull Request للمراجعة.

## 10. قرارات تم اتخاذها

1. **تطبيق واحد** للموظفين والموكلين: الواجهة تتغير حسب دور المستخدم بعد تسجيل الدخول.
2. **التوزيع:** في البداية مباشرة (ملف APK لأندرويد)، ثم النشر على المتاجر (Google Play وApp Store) في مرحلة لاحقة.
   - أندرويد: التوزيع المباشر ممكن عبر رابط تنزيل APK.
   - iOS: لا يوجد توزيع مباشر عمليًا؛ يتطلب حساب مطور Apple واستخدام TestFlight أو النشر على المتجر.

## 11. أسئلة مفتوحة

1. كم عدد المحامين والموظفين المتوقع استخدامهم للتطبيق؟
2. أي بوابة دفع يفضلها المكتب؟
3. أي أنواع القضايا الأكثر شيوعًا في المكتب لنبدأ بها؟
